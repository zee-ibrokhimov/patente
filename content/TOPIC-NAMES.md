descriptions of scope rather than as labels — the longest is 250 characters — so the app
shows everything up to the first clause.

For most topics that already lands well: *Segnali di pericolo*, *Limiti di velocità*,
*Uso delle luci* need nothing. Only 10 of 25 break, and those are marked **fix**.

For each of those, either accept my draft or write over it in the last column. Two to
four words, whatever a candidate would actually call it. Send the file back and I will
wire it in as a lookup table — the ministerial name stays in the database, this is only
what gets displayed.
